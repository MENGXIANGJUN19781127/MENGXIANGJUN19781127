## 中文

### 关于我

职业编剧。做两件事：**把故事做成能拍的东西**，和**把重复的判断做成可复用的系统**。

剧本开发上走两条并行轨道，方法论严格分开、互不套用：

- **横屏中剧**——单集 15–20 分钟，单集自成微型四幕（冷开场立钩 → 建置引爆 → 对抗升级 → 集尾扣子），人物弧线与长线悬念铺陈；
- **竖屏短剧**——单集 2–3 分钟，每集一钩子、高频反转，集尾扣子同时抬高希望与恐惧。

从立项、分集大纲、分场到正式剧本全程推进，同时做结构诊断、可演性检查与改稿版本核验。收尾时只关心一件事：**这一场里，谁想从谁手里拿到什么，谁在拦着，结果改变了什么。**

### 方法论沉淀

把编剧理论编译成**可调用、可验收的技能库**——人物卡、商业引擎与钩子链、对白铁律、连续性检查、格式交付。理论不写在纸上吃灰，写成能跑的闸门：每条规则要么有可执行的判据，要么标清楚它验不了什么。

### AI Agent 工具链

用多智能体工作流辅助创作与研究：

- **Hermes Agent** 技能系统——按创作阶段调度的方法论模块
- **Obsidian 知识库**——LLM Wiki 四层架构（原始资料 / 编译层 / 索引总线 / 只读真相源）
- **长期记忆层**——把有证据来源的结论沉淀为可追溯的记忆

## English

### About

I'm a professional screenwriter. I do two things: **turn stories into something shootable**, and **turn repeated judgment calls into reusable systems**.

Two parallel development tracks, with strictly separate methodologies that are never mixed:

- **Mid-length drama (landscape)** — 15–20 min per episode, each episode a self-contained mini four-act (cold open hook → setup ignition → escalation → episode-end hook), with character arcs and long-line suspense.
- **Short-form vertical drama** — 2–3 min per episode, one hook per episode with high-frequency reversals, where each episode-ending hook raises hope and fear at the same time.

I work end to end: greenlight gate, episode outlines, scene breakdowns, full scripts — plus structural diagnosis, playability checks, and version verification. Everything comes back to one question: **in this scene, who wants what from whom, who's blocking it, and what changed as a result?**

### Methodology as infrastructure

I compile screenwriting theory into a **callable, verifiable skill library** — character systems, commercial engines and hook chains, dialogue rules, continuity checks, delivery formats. Theory shouldn't sit in a drawer; it becomes a gate that runs or a judgment that states plainly what it cannot verify.

### AI agent tooling

Multi-agent workflows for writing and research:

- **Hermes Agent** skill system — methodology modules dispatched by development stage
- **Obsidian knowledge base** — four-layer LLM Wiki (raw sources / compiled layer / index bus / read-only truth)
- **Long-term memory layer** — evidence-backed conclusions kept traceable

### Currently working on

- Pipelines for screenplay engineering: greenlight gate → episodes → scenes → draft → acceptance
- Film/TV intelligence monitoring: vertical short-drama charts and mid-length revenue-share drama data
- Maintaining and open-sourcing agent skills
